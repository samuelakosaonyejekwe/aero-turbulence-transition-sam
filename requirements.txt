# Pinned to the environment every number in this repository was computed in.
#
# The results here are a claim about reproducibility, and an unpinned
# requirements file does not support one: `pip install -r requirements.txt`
# resolves to whatever is current on the day it is run.  Two of these pins are
# load-bearing rather than cautious.
#
#   numpy   - numpy 2.0 renamed trapz to trapezoid and deprecated the old
#             spelling, which is slated for removal.  solver/stability.py binds
#             whichever exists (`_trapz`), so the code runs on 1.x and 2.x
#             alike; the pin is here because the floating-point results - the
#             Falkner-Skan family, and the amplification database built from it
#             - belong to the version that generated them, not because the
#             source needs this one.
#   scipy   - solve_bvp settles the Falkner-Skan family, including the
#             reverse-flow branch that the separation-bubble amplification rate
#             is read from.  A different solver version can converge to the
#             same profiles to a different last digit, which moves the
#             tabulated rates in the last digit too.
#
# The upper bounds are the next major version, not a guess at what will break.
# To move off a pin, change it here, run `python3 tools/smoke.py`, then
# `python3 tools/pipeline.py` and `python3 tools/baseline.py diff <snapshot>`,
# and read what moved before believing the new environment.
